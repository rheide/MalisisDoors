# Malisis Doors: native 1.21.1 alpha

This working subset includes six standard doors and sixteen curtain colours. It is not a full port. See [the feature and validation report](PORT-STATUS.md) for exact coverage, limitations and reproduction instructions.

Build with Java 21: `./gradlew build --no-daemon`. The sibling `core-modern` is built as a separate dependency JAR. Original assets are MIT-licensed; see LICENSE.txt. The NeoForge MDK license remains in TEMPLATE_LICENSE.txt.
