# Malisis Doors: native 1.21.1 port in progress

The current development branch has validated standard doors/curtains, large/model mechanisms, trapdoors, camouflage gates and rusty ladders. Door Factory/customization and the remaining parity work are tracked in [PORTING-CHECKLIST.md](PORTING-CHECKLIST.md). The earlier 22-variant alpha is not a complete port.

Build with Java 21: `./gradlew build --no-daemon`. The sibling `core-modern` is built as a separate dependency JAR. Original assets are MIT-licensed; see LICENSE.txt. The NeoForge MDK license remains in TEMPLATE_LICENSE.txt.
